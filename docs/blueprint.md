# **App Name**: IlmQuest: Islamic Knowledge Game

## Core Features:

- Avatar Customization: Create and customize an Islamic-themed avatar with various clothing options and ethnicities.
- Adaptive Quiz Engine: Provide multiple-choice, true/false, and fill-in-the-blank questions across 25 Islamic knowledge categories with difficulty adjusted based on the user's performance.
- AI-Powered Lifeline Assistance: Offers a tool where users can 'Ask the Imam,' receiving hints generated by AI that draw on Islamic teachings.
- Ranking and Progression: Advance through nine ranks, from 'Mubtadi' to 'Mujaddid', unlocking badges and titles based on quiz performance and knowledge milestones.
- Streak Rewards: Incentivize daily engagement with increasing rewards for maintaining learning streaks.
- Prayer Time Integration: Integrate location-based prayer times with gentle reminders and themed backgrounds during prayer times.
- Daily Hadith Display: Show a rotating inspirational quote with beautiful typography each day.

## Style Guidelines:

- Primary color: Emerald Green (#006B3C), symbolizing growth and prosperity.
- Background color: Pearl White (#FAF9F6) for a clean and pure aesthetic.
- Accent color: Gold (#D4AF37), representing divine wisdom and achievement. Provides high contrast against the background.
- English/Urdu body and headline font: 'PT Sans', a humanist sans-serif for headlines and body.
- Use hand-drawn style icons with Islamic motifs.
- Employ subtle Islamic geometric patterns as background overlays at 20% opacity.
- Incorporate smooth transitions and star particle effects for correct answers.
